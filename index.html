Case study

Logística 7 Cajas

CUSTOM-BUILT DELIVERY SYSTEM · IN PRODUCTION SINCE 2026

7 Cajas Distribuidora is a wholesale distributor of premium high-oleic sunflower oil (SEDA and LOT brands) for the food service and industrial sector. Deliveries to stores were coordinated over WhatsApp from a spreadsheet built by hand in Google Sheets, with no real-time visibility into who had delivered what. I designed and shipped to production a system that doesn't ask anyone to change the way they work — the spreadsheet remains the source of truth, and turns into a coordinated delivery run with live tracking, without any Google account or API involved.

HOW IT WORKS
  1. 01The salesperson builds the route as always, in a Sheets tab.
  2. 02Selects everything, copies it, and pastes it into the web panel. A custom parser interprets the text and shows a preview before confirming.
  3. 03Each driver opens the app on their phone, picks which of the day's stops are theirs, and orders them.
  4. 04As they deliver, the panel updates itself: a live per-driver checklist — pending / delivered / skipped.

ENGINEERING DECISIONS
  • Custom, deterministic parser (no AI) that turns the pasted spreadsheet into structured data, isolated in a single file so format changes never touch the rest of the system.
  • Real-time sync between the panel and the drivers via Supabase Realtime: every status change shows up instantly on both ends.
  • In-progress stops are frozen: if the salesperson updates the route mid-day, it won't overwrite work a driver has already started delivering.
  • Hand-mapped native navigation: Android's back button/gesture is handled screen by screen across the whole PWA, so it never breaks the driver's flow.
  • Zero-downtime schema evolution: six incremental Supabase migrations (multi-product, split payment, new statuses) applied to a database with real data in daily use.
  • Infrastructure upkeep: automated keep-alive via GitHub Actions so the free Supabase project never pauses from inactivity.

In daily use since 2026, replacing manual WhatsApp coordination and hand-built spreadsheets. Drivers completely dropped WhatsApp for coordinating deliveries, and office staff stopped typing message by message: with one button they copy each client's data and paste it in, marking each one green as it's processed, keeping track of what's left without losing the thread. The delivery history, once drawers full of paper receipts, is now digital and searchable, improving and streamlining the administrative workflow. According to the drivers themselves, the load of tasks that used to be tedious — reconfirming who delivered what, chasing scattered messages — dropped noticeably. Four tagged releases (v1.0 → v1.3) and continuous iteration based on what they themselves ask for.
